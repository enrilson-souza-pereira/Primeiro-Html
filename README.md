# 🌐 Meus Sites Favoritos

Uma página web simples e moderna desenvolvida com **HTML5** e **CSS3** para exibir uma lista personalizada de sites favoritos, contendo logotipos/imagens ilustrativas e links diretos para acesso rápido.

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização visual (responsividade básica, fontes, cores, cartões/containers, sombras e efeitos de hover).

---

## 🎨 Funcionalidades

* **Cards Individuais:** Cada site é exibido em um container próprio (`.site-container`) com sombra e bordas arredondadas.
* **Imagens Ilustrativas:** Logos dos sites redimensionados e centralizados com ajuste proporcional (`object-fit: contain`).
* **Links Diretos:** Acesso aos sites tanto clicando na imagem quanto através do link textual dedicado (abrindo em uma nova aba do navegador).
* **Responsividade e Design Limpo:** Layout centralizado com paleta de cores agradável e feedback visual ao passar o mouse sobre os links (`:hover`).

## 💻 Como Executar o Projeto

1. Faça o download ou clone este repositório.
2. Certifique-se de que o arquivo principal está salvo como **`index.html`**.
3. Dê um duplo clique no arquivo **`index.html`** ou abra-o em qualquer navegador web moderno (Google Chrome, Firefox, Edge, Safari, etc.).

---

## 🛠️ Personalização

Para personalizar a página com os seus próprios dados:
* Abra o arquivo `index.html` em um editor de código (como VS Code, Bloco de Notas, etc.).
* Altere o texto `<h1>Meus sites favoritos: xxx</h1>` substituindo o `"xxx"` pelo seu nome.
* Adicione, remova ou edite os blocos `<div class="site-container">...</div>` para incluir os seus próprios links e imagens favoritas.# Primeiro-Html
